# WEB DEVELOPMENT ASSIGNMENT

## Three Website Projects

### 1. Project Overview

This project contains three websites developed using HTML and CSS:

1. Personal Portfolio Website
2. NRI University Vijayawada Website
3. Sweet Treats Bakery Website

### 2. Files Included

**Portfolio Website**

* portfolio.html
* portfolio.css

**College Website**

* college.html
* college.css

**Bakery Website**

* bakery.html
* bakery.css

### 3. Technologies Used

* HTML5 — To create the structure and content of webpages.
* CSS3 — To add colours, styles, spacing, layouts, and effects.

### 4. Software Required

* Google Chrome, Microsoft Edge, or another web browser.
* Notepad or Visual Studio Code.

### 5. How to Run the Websites

1. Extract the project ZIP file.
2. Keep each HTML file and its corresponding CSS file in the same folder.
3. Double-click the HTML file you want to open.
4. The website will open in your web browser.
